A one-line weather forecast for a city that doesn't exist, written to
charm a bored commuter waiting at a rainy bus stop.

Running `main.py` writes a single 122-character forecast line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> In Wobbleton, sunny spells with a 90% chance of spontaneous conga lines — 24°C, bring sunscreen and your best dance shoes.

## Run

```sh
python3 main.py
```
